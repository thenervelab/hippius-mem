The gap

An agent without memory is just a function. Shared memory is usually a leap of faith.

Most memory layers solve the first half — they remember things. But for a team, three harder questions go unanswered: who can read it, can you trust what came back, and does every machine see the same thing.

01 The eternal now

Between calls the model forgets everything. Teams paper over it with copy‑pasted context and per‑machine scratch notes that drift out of sync.

02 Trust the vendor

Hosted memory layers store your team's facts in a database you don't control, in plaintext the provider can read. "It came back from the API" is the only integrity guarantee you get.

03 No chain of custody

When a wrong "convention" poisons every agent's context, there's no signed record of who wrote it, when, or whether it was tampered with after the fact.

How it works

One shared bucket is the source of truth. Four planes derive everything else from it.

A note is one self‑contained fact with a one‑line summary and a full body. Notes are scoped by team and repo, encrypted client‑side, and stored as objects. The index is a disposable cache — it rebuilds from the team's op‑log at any time.

The signature property

Every memory carries a verifiable chain of custody.

The shared bucket is treated as untrusted — a peer or the provider could add, edit or drop objects. So trust isn't assumed; it's re‑derived from signatures and hashes on every read. A forged or reordered op fails verification. Anyone can confirm an op was committed under a given root without trusting the server.

Retrieval honesty

Lexical by default, semantic when you want it — always private.

Default: recall ranks with a deterministic 64‑dimension bag‑of‑tokens hash embedder fused with keyword overlap and recency. Zero dependencies, zero download — it captures word co‑occurrence, not meaning, so a pure paraphrase can slip past it.

Opt‑in: build with --features embeddings and a real dense model — all‑MiniLM‑L6‑v2, 384‑dim, via local ONNX — embeds queries and summaries so paraphrases match. The honest cost: a one‑time ~90 MB model download and a heavier dependency, which is exactly why it's off by default. The decisive part: embedding runs in‑process — no query or note text is ever sent to an external API, so unlike a cloud memory layer, turning on semantic search doesn't hand your data to anyone. The trust, privacy and verifiability properties hold either way.

The interface

Nine MCP tools your agent already knows how to call.

Hippius Memory is a stdio MCP server. Register it in Claude Code (or any MCP client) and the agent gets these primitives. The recall / get split keeps context lean; the rest mutate through the signed op‑log.

remember

Store a note — type, summary, body, tags. Appends a signed op; returns a mem_… id.

recall

Search team memory. Returns ranked pointers — id, summary, score, author, updated. Never bodies.

get

Hydrate one note by id, including its full body. The other half of the context‑efficiency split.

refresh

Replay the team op‑log into this machine — pulling in teammates' notes and applying their tombstones.

forget

Tombstone a note (logical delete). A signed Forget op; the note stops surfacing in recall.

link

Assert a directed link from one note to another. A signed Link op in the shared log.

edit

Update a note in place, preserving its identity, created time and links. A signed Edit op.

history

The full op history of a note, in convergence order, each anchored op carrying a Merkle inclusion proof.

reconcile

Cross‑check the visible op‑log against anchored roots — flags any missing op or mismatched root.

Threat model

What the guarantees buy you — and what they don't.

Trust comes from saying the limits out loud. The bucket is untrusted, and the hash chain catches in‑chain tampering — but a few things still need out‑of‑band care or the opt‑in chain feature.

↺
Removal isn't instant revocationMembership filtering stops a removed member's new ops from converging, but their sub‑token must be revoked and the team key rotated to fully cut access.
⛓
Local mode detects loss, not suppressionreconcile catches accidental op‑log loss. Catching adversarial suppression needs the chain feature plus chain readback.
✎
The chain catches edits, not truncationThe per‑author hash chain detects in‑place edits and reordering — not tail‑truncation, whole‑author suppression, or split‑view equivocation on its own.
⚓
Anchoring is after‑the‑factAn op dropped before its batch anchors leaves no commitment. A lower anchor threshold shrinks that window but never closes it.
Run it

Give your team one memory. Keep the keys.

Build the binary, point it at a team bucket, and register it as an MCP server. Each developer holds their own S3 sub‑token to the one shared bucket; the team key encrypts every note before it leaves the machine.

  terminal
# build the release binary
cargo build --release

# verify the bundle + prove the encryption boundary
hippius-mem doctor          # live seal→put→get→open probe

# register it as a stdio MCP server in Claude Code
claude mcp add hippius-mem -- ./target/release/hippius-mem
